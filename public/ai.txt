# Información para sistemas de IA

- Para conocer las rutas públicas de contenido: https://montecristi.net/llms.txt
- Para descubrir páginas: https://montecristi.net/sitemap.xml
- Para artículos recientes: https://montecristi.net/news-sitemap.xml

- Las reglas de acceso se publican en: https://montecristi.net/robots.txt

Este archivo es informativo y no reemplaza robots.txt ni otras instrucciones compatibles con cada rastreador.
